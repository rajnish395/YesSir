# 🎓 yesSir

### College Management & Administration Platform

**yesSir** is a full-stack college management platform designed to simplify user management, authentication, and administrative operations through a centralized dashboard.

---

## ✨ Features

* 🔐 User Authentication
* 👥 User Management
* 🛡️ Role-Based Access Control
* 📊 Admin Dashboard
* 🎓 Student Management
* 👨‍🏫 Faculty Management
* 🆔 QID-Based User Identification
* 🔎 User Search & Filtering
* 🔑 Secure Password Handling
* 🌐 REST API Integration

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/rajnish395/yesSir.git
cd yesSir
```

### 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 3. Install Backend Dependencies

```bash
cd ../backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend directory.

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
PORT=5000
```

> ⚠️ Never commit your `.env` file or expose secret keys publicly.

---

## ▶️ Running the Project

### Start Backend

```bash
cd backend
npm start
```

### Start Frontend

Open another terminal:

```bash
cd frontend
npm run dev
```

The application will then be available through the local development URL shown by Vite.
